How to get Video, MP3 & GIF

Use the main app (index.html) to pick a YouTube clip, set the time range and metadata, then run the pipeline. You get a video (MP4), an MP3, and optionally a GIF.

Demo

Quick walkthrough of the app: YouTube URL, clip range, Apply, and result (Video / Gif, subtitles).

1. Paste the YouTube URL

In the main area, paste a YouTube watch URL (e.g. https://www.youtube.com/watch?v=…). The preview loads so you can scrub and set the exact clip.

2. Set output and metadata (left panel)
  • Output Filename — base name for all files (e.g. myclip → myclip.mp4, myclip.mp3, myclipGif.mp4).
  • Artist and Title — used for the MP3’s ID3 tags.
  • Reverse / Loop GIF — optional, for the GIF output.
3. Set the clip range

Use the Start Time and End Time sliders, or play the YouTube preview and click Set Start Position / Set End Position to snap the range to the current playback time. Values are in milliseconds (ms). You can edit the number next to each slider or move the slider; both stay in sync. The range must be at least 100 ms (end > start + 100).

4. Apply (run the pipeline)

Click Apply. The backend will:

  1. Download the clip as MP4 (via yt-dlp).
  2. Extract MP3 from that clip (ffmpeg) and write ID3 artist/title (id3v2).
  3. Optionally produce a GIF (with or without subtitles; see below).

A loading modal appears while the job runs. When it finishes, the UI shows the result video, a Video / Gif source selector, and (if you didn’t use Reverse Loop) the subtitles table so you can add or edit captions for the next run.

5. After Apply: result video and source selector

Once the pipeline completes, the result area shows:

  • Video / Gif — A dropdown to switch between the MP4 clip and the generated GIF. Use it to preview both outputs.
  • Subtitles table — Visible only when Reverse / Loop GIF is unchecked. Use it to define captions that will be burned into the GIF on the next Apply (see below).
6. Subtitles (for GIF)

You can burn one or more subtitles into the GIF. The subtitles table appears under the result video after a successful run, as long as Reverse / Loop GIF is off (reverse loop and subtitles cannot be used together).

  • Start / End — Time range for the subtitle, in milliseconds (ms), within the clip. Use the Start and End buttons to set the first row’s times from the result video’s current playback position.
  • Value — The caption text.
  • Font — Impact or Arial Black.
  • Size — Font size (12–48).
  • Color — White, Black, Light Green, Light Orange, Yellow.
  • Position — Top or Bottom.
  • ➕ / ➖ — Add a new subtitle row (clone times from the previous row) or remove a row.

Subtitle times must fall within the clip duration. After editing, click Apply again to regenerate the GIF with the new subtitles. The table is pre-filled with one row; add more as needed.

7. Where are the files?

Outputs are written to the server’s output folder (by default public/output/). You get:

  • <filename>.mp4 — video clip
  • <filename>.mp3 — audio with ID3 tags
  • <filename>Gif.mp4 — GIF (or looped clip)
8. Keyboard shortcuts

In the app, press ? (or click ⌨️ Shortcuts in the header) to open the shortcuts modal. Space and arrow keys only apply when focus is not in a text field.

  • Ctrl/⌘ + Enter — Apply (cut video / MP3 / GIF)
  • Space — Toggle result video play/pause
  • ← / → — Skip result video backward / forward (0.5 s)
  • ? — Show keyboard shortcuts modal
  • + — Add Table Subtitle
  • - — Remove Top Table Subtitle

Validation: The app checks that the YouTube URL is non-empty, the clip range is valid (end > start + 100 ms), and subtitle times (if any) fall within the clip. Errors appear in the Minsi Log (left panel) or in a modal for critical failures.

If the app reports missing dependencies (e.g. yt-dlp, ffmpeg), install them on the machine where the backend runs and ensure they are on the system PATH. See the project README for the full list.
